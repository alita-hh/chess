### 5.7 等级认证模块（新增核心准入流程）

本模块为报名核心前置条件，承载用户等级评定申请、证书上传、以及实体证书邮寄诉求。

#### 5.7.1 页面清单与路由

| 页面 | 路由 | 说明 | 需登录 |
| --- | --- | --- | --- |
| 认证中心首页 | `/certification/index` | 查看当前等级、历史申请记录 | **是** |
| 提交认证申请 | `/certification/apply` | 填写资料、上传证书、选择邮寄 | **是** |
| 认证详情与进度 | `/certification/detail/:id` | 查看某次申请的审核进度或驳回原因 | **是** |

#### 5.7.2 认证中心首页 (`/certification/index`)

**模块组成：**

1. **当前等级卡片**
   - 已认证：高亮展示当前获得的最高棋力等级（如：中国象棋一级棋士）、发证日期。
   - 未认证：显示「暂无等级认证」，并提供「去认证」主按钮。

2. **历史申请记录列表**
   - 按提交时间倒序排列。
   - 卡片字段：申请等级、提交时间、状态徽章（审核中 / 已通过 / 已驳回）。
   - 点击卡片进入「认证详情与进度」页。
   - **空态：** 暂无历史申请记录。

#### 5.7.3 提交认证申请页 (`/certification/apply`)

**表单字段：** 真实姓名、身份证号（18位校验）、申请级别、等级证明材料（最多3张）、申请纸质证书开关、邮寄地址（开关开启时必填）。

**提交校验：** 存在「审核中」申请时禁止重复提交（BR-10）。

#### 5.7.4 认证详情与进度 (`/certification/detail/:id`)

C 端合并展示审核状态（BR-09）：0/2→审核中，3→已通过，1/4→已驳回。

#### 5.7.5 数据模型

见 `store` 中 `xq_certifications` 与 PRD 7.7 字段定义。

#### 5.7.6 业务规则

- **BR-08：** 活动报名前校验 `User.currentLevel` 与 `Activity.minLevelRequired`。
- **BR-09：** C 端合并审批状态展示。
- **BR-10：** 同时仅允许一笔审核中申请。
